## Why this project

Most "data analyst SQL project" repos on GitHub follow the same shape: write some queries, screenshot the output, done. This one goes a step further — it wraps the analysis in an AI layer so the project is a *working tool*, not just a report:

- Type a question in plain English → an LLM converts it into a real SQL query
- The query runs live against the actual job postings database
- The results come back with an AI-generated, plain-English insight

It's built on top of a genuine relational schema (fact table + dimension tables), so the underlying SQL work is the same rigor as a classic analytics project — the AI layer sits on top of it, not instead of it.

## Architecture

```
User question (plain English)
        │
        ▼
  Claude (text-to-SQL)  ──▶  generates a single SELECT query
        │
        ▼
  PostgreSQL database  ──▶  executes the query (read-only, guarded)
        │
        ▼
  Claude (summarization)  ──▶  writes a plain-English insight
        │
        ▼
  Streamlit UI  ──▶  shows the SQL, the results table/chart, and the insight
```

## Database schema

| Table | Purpose |
|---|---|
| `job_postings_fact` | One row per job posting — title, location, salary, dates, etc. |
| `company_dim` | Company details |
| `skills_job_dim` | Bridge table linking job postings to skills (many-to-many) |
| `skills_dim` | Skill names and skill types |

## Features

### 🤖 Ask the AI Analyst
Type any question about the dataset ("Which skills pay the most for remote Data Analyst roles?") and get back the generated SQL, a results table, an auto-generated chart, and a written insight — all live.

### 📌 Pre-built SQL analysis (`project_sql/`)
Eight hand-written queries covering the classic analyst questions plus three deeper ones:

1. Top-paying Data Analyst jobs
2. Skills required for the top-paying jobs (CTE)
3. Most in-demand skills overall
4. Skills with the highest average salary
5. Most "optimal" skills — high demand *and* high salary (`HAVING`)
6. **Top 3 skills per job title** — window function (`DENSE_RANK() OVER (PARTITION BY ...)`)
7. **Skill co-occurrence** — which skill pairs appear together most often (self-join)
8. **Quarterly salary trend** — average salary over time (date functions)

### 🔒 Guardrails
Because SQL is generated by an LLM from free-text input, `src/db.py` enforces:
- Only `SELECT` statements are allowed
- Forbidden keywords (`INSERT`, `UPDATE`, `DELETE`, `DROP`, etc.) are blocked
- No stacked/multiple statements
